# 使用复选框控件

要插入复选框，必要的前置条件是 Excel 的 “开发工具” 选项卡是激活的。

在 Excel 中，选择 **文件** > **选项**。在 **Excel 选项**对话框中，单击**自定义功能区**，勾选**开发工具**选项，然后单击**确定**启动 ”开发工具” 选项卡。

![](_images/drawingbed/img/Pasted%20image%2020260920103354.png)

此时，我们便可以在 ”开发工具“ 选项卡中插入 ”表单控件复选框“ 或者 ”ActiveX 控件复选框“。

![](_images/drawingbed/img/Pasted%20image%2020260920104032.png)

> “表单控件复选框” 比 ”ActiveX 控件复选框“ 简单得多，在日常办公中，表单控件足够使用。当我们需要更细致修改复选框时，才考虑使用 ”ActiveX 控件复选框“，其提供更多的格式设置选项。

# 使用注意

- “表单控件” 是一个可复制的控件（”ActiveX 控件“ 不行）。将目标控件移动到单元格内后，对这个单元格进行复制，“表单控件” 可以向文字一样粘贴到其他单元格，包括自动填充也支持。

![](_images/drawingbed/img/Pasted%20image%2020260920105753.png)

- 如果需要对 ”控件“ 进行编辑，则需要将 ”鼠标“ 移动到 ”控件”，然后 “右键” > “编辑文字” 或 “设置属性” 或 “形状格式”。
- 如果需要对 “控件” 进行删除，则需要在按住 "Ctrl” 并点击 “控件” 选中后，按下键盘 ”Delete“ 进行删除。

![](_images/drawingbed/img/Pasted%20image%2020260920110146.png)
