# 在输入法中候选

在中文输入法中，当你输入“对“，“对勾” 时，输入法会自动展示 ”√“ 的候选，你可以直接选择。

![](_images/drawingbed/img/Pasted%20image%2020260920101002.png)

# 插入其他符号

在 Excel 中，选择 「插入」→「符号」→「其他符号」，字体选择 ”Wingdings“ 或 ”Segoe UI Symbol“，在候选中可以找到 ”√“。

![](_images/drawingbed/img/Pasted%20image%2020260920101354.png)

# 更换字体后输入

在字体中，切换字体到 “Wingdings 2”，此时，直接在输入框输入 ”P“，就可以插入 ”√“。

![](_images/drawingbed/img/Pasted%20image%2020260920102120.png)
